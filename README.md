# เที่ยวเกาะหลีเป๊ะ.com

เว็บข้อมูลท่องเที่ยวเกาะหลีเป๊ะ จังหวัดสตูล — ทัวร์ ที่พัก เรือ และร้านอาหาร

## โครงสร้าง

- `index.html` — หน้าหลัก
- `contact.html` — ติดต่อ
- `article.html` — หน้ารายละเอียด
- `css/style.css` — สไตล์
- `js/main.js` — carousel, การ์ด, แผนที่
- `better-together/` — ฟอนต์ Better Together

## GitHub Pages

1. เปิด [Settings → Pages](https://github.com/goddarkmarketing/KOHLIPE/settings/pages)
2. **Source:** เลือก **GitHub Actions**
3. Push ไป `main` แล้ว Action จะ deploy อัตโนมัติ

URL: https://goddarkmarketing.github.io/KOHLIPE/

## รันบนเครื่อง

วางในเว็บเซิร์ฟเวอร์ (เช่น XAMPP) แล้วเปิดผ่าน localhost
